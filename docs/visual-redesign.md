# بازطراحی بصری بلوتل

نسخه پیشین در commit `c47313a` و شاخه `feat/buluttel-website` محفوظ است. تغییرات جدید فقط در شاخه `feat/buluttel-visual-redesign` قرار دارند؛ بازگشت با انتخاب شاخه قبلی ممکن است.

## جهت طراحی و ساختار

پالت اصلی: Midnight Navy `#07152E`، Electric Blue `#1264F5`، Cyan `#18C9D5`، Violet `#815CF6` و Ice White `#F5F8FF`.

صفحه اصلی هشت ترکیب‌بندی دارد: Hero تیره با کنسول تماس اختصاصی، معرفی ارزش با ستون‌های بدون کارت، نمایش سناریوهای محصول در زمینه تیره، مسیر سه‌مرحله‌ای تماس، راهکارهای سازمانی در فهرست تصویری، چارچوب هزینه بدون قیمت، مجله با چیدمان تحریریه و CTA پایانی تیره. در موبایل ترتیب خواندن و مقیاس عناصر مستقل تنظیم شده‌اند.

- `src/app/page.tsx`: محتوای اصلی Server Component و HTML استاتیک.
- `src/app/redesign.css`: هویت بصری، قواعد responsive و motion؛ `globals.css` پایه صفحات محتوایی را نگه می‌دارد.
- `src/components/call-console.tsx`: نمای مفهومی اختصاصی مدیریت تماس با SVG و CSS، بدون تصویر حجیم یا کتابخانه سه‌بعدی.
- `src/components/scenario-explorer.tsx`: سه سناریوی محلی؛ دکمه‌های دارای aria-pressed و مقصد مشخص. هیچ تماس یا درخواست شبکه‌ای انجام نمی‌دهند.
- `src/components/reveal.tsx`: IntersectionObserver و Web Animations برای reveal یک‌باره؛ بدون مخفی‌کردن محتوا در حالت بدون JavaScript، با cleanup و پشتیبانی از تغییر prefers-reduced-motion در زمان اجرا.
- سربرگ و صفحات داخلی: مقیاس تیتر، رنگ متن، وضعیت صفحه جاری، بستن منوی موبایل با Escape و بازگشت focus به دکمه منو.

موج صدا با transform و کارت شناور با translate حرکت می‌کنند؛ فضای آن‌ها از ابتدا رزرو شده است. هیچ dependency جدیدی برای حرکت یا طراحی اضافه نشده است. نمایش اپراتورها و داخلی‌ها نمونه است، نه داده واقعی یا تأیید قابلیت محصول. توضیح مفهومی کنار نمایش‌ها باقی مانده است؛ فرم مشاوره همچنان disabled است.

## اعتبارسنجی

- Build production، TypeScript و بررسی استاتیک ۱۳ صفحه موفق.
- همان metadata، canonical، JSON-LD، robots، sitemap و قرارداد Static Export حفظ شده‌اند.
- آزمون Chromium در عرض‌های ۱۴۴۰، ۷۶۸، ۳۹۰ و ۳۲۰ پیکسل: کنترل overflow برای هر ۱۳ مسیر، جابه‌جایی سه سناریو، نبود خطای JavaScript و منوی موبایل.
- با reduced motion، موج‌ها و عناصر شناور animation ندارند و reveal فعال نمی‌شود.
- بدون JavaScript، هشت بخش اصلی و سناریوی اولیه قابل مشاهده‌اند؛ محتوای HTML و مسیرهای لینک باقی می‌مانند.
- اسکرین‌شات‌های موبایل و دسکتاپ در محیط محلی بررسی شدند؛ مقیاس عنوان داخل کنسول در موبایل مستقل از تیترهای صفحه اصلاح شد.

این نتایج معادل آزمون شبکه Cloudflare، ممیزی رسمی accessibility یا اندازه‌گیری Lighthouse/Core Web Vitals نیستند. اندازه‌گیری میدانی و تأیید اطلاعات تجاری پیش از انتشار رسمی لازم است. تنظیم انتشار تغییری نکرده: `npm run build` و پوشه `out`؛ هیچ DNS یا merge انجام نشده است.
